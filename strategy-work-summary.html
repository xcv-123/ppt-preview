两年工作在战略屋里的位置

LEAPMOTOR 郭静 · 产品经理 · 营销运营部
现职级 P3-B · 申请 P4-A · 2025.01—2026.11
战略愿景

成为驱动零跑全球增长的核心智能引擎，构建超百万级用户与伙伴共赢的数智生态。

两年工作只对两条业务组合：公域投放效率、车主服务。前者靠用户在公域发帖形成内容供给；后者靠服务管家 IM 把售后协同做成可自动运转的子系统。

业务组合上的落点

对应战略意图「强体验」与「助决策」。其余业务组合不在这两年的主责范围。
强体验

提升公域投放效率

内容供给

公域投放要的不是多开一个站内频道，而是让车主和创作者愿意、并能稳定地在抖音、小红书、汽车之家等公域发帖。两年做的是从 0 到 1 把这条供给链建起来，再让审核和采集自己运转。

创作者平台

2025 从 0 到 1：达人招募、任务、奖励、站外发帖覆盖抖音 / 小红书 / 汽车之家 / 懂车帝 / 头条 / 微博。2026 主投入 13 份：OCR、申诉、AI 自动审核、开放普通用户、分层报名配额、数皆看板与补推。把活动报名工具做成可审核、可分层的公域内容供给中台。

口碑生产

问卷二次打扰改为抓汽车之家口碑：1.0 精简维度，2.0 取消问卷改抓取，3.0 按 9 月 17 日前后统一历史口径。指标从回收量改为点评量、单条处理耗时、详情转化，让公域口碑能直接用于站内决策与投放。

对外投放

UGC 可同步抖音与小红书；分享组件统一；专题页用 uid / openid 溯源；登录浮层按渠道管理，并可按渠道看 PV / UV。公域帖既能发得出去，也能回到站内量出投放效果。

供给风控

未传截图占 36.66% 时先补上传规范；审核顺序定为运营、规则、AI；按人群限制单日报名名额，避免羊毛党挤占公域活动名额，保证投放供给质量。

助决策

提升车主服务

主责子系统

车主服务的核心是服务管家 IM：用户在 APP 里问得到人，门店和总部跟得上，重复咨询由系统先答。同一条主线从自动建群叠到自动化和群机器人，不另起炉灶。

服务 IM

一期自动建群与三级权限 → 二期运营闭环 → 移动端 → 大区 / 小区权限与根因修复 → 五项自动化（第一次写 ROI：22 人天、投入 4.4 万、年收益测算 36 万、ROI 约 7.1）→ 群机器人可独立回复。

充电问答

手册充电章节、充电资讯、IM 素材做成 RAG。只答充电；高压用电、费用、需到店诊断、改装破解使用固定拒绝话术。置信度不足就不答，方案目标为首响不超过 3 秒。

服务效率

敏感词自动建单、跟进单强制截图、推送按订单 / 充电桩状态触发。试驾车用企微批量解锁功能，单次最多 2000 台，减少门店重复答题，把管家时间留给复杂问题。

数据主体

客户主体从 uid 改为 vin；工单带触发前后各 20 条群消息；会话直接调用用户信息、销服维修记录和素材库，让管家决策有据，而不是靠记忆补位。

潜客
想买车的人
场景 · 看车、看口碑、被公域内容种草
查看口碑 年终报告 创作者活动 UGC→抖音/小红书 AI 搜索

我做了什么：口碑取消问卷、改抓汽车之家，1.0 精简维度 → 2.0 抓取 → 3.0 统一历史口径；创作者平台开放潜客参与；UGC 可同步抖音 / 小红书；搜索热度可配，并引入 AI 搜索 / 充电 RAG；年终报告可生成与分享；专题页 uid / openid 溯源，分享组件统一。

满意度：少被二次问卷打扰，公域真实口碑与内容更多；搜得到、看得真；从公域回流站内路径清楚，渠道效果可追踪。

场景 · 留资、接受转介绍邀请、注册试驾
注册渠道 2.0 转介绍接受页 登录浮层 线索下发 隐私合规

我做了什么：注册渠道覆盖 APP / 小程序 / H5 / 转介绍 / 商城 / 官网试驾等 9 类场景，线索是否下发零小跑改为后台可配；接受邀请页先勾隐私再发验证码；登录浮层按渠道管理并可看 PV / UV；邀请码「6 个月未留资」改为按注册时间起算；D19 留资门店过滤；转介绍首页改任务中心并支持商品券。

满意度：留资后跟进更准，隐私提示清楚，不同入口体验一致；少被错误标签和无效激励误伤。

场景 · 预定 / 共同用车，提前进入用车与社群
创作者开放人群 共同用车人课堂 社区风控 年终报告

我做了什么：创作者平台人群扩到潜客、预定车主、共同用车人；车主课堂支持共同用车人答题，解锁只作用绑定车辆；社区风控补齐机审 / 人审 / 可重置；年终报告、AI 搜索在购前到购后早期持续可用。

满意度：进门前也能参与活动和学车，不被达人门槛挡住；内容更干净；误开功能风险下降。

车主
已购车的人
场景 · 转介绍邀友、公域发帖帮品牌种草
转介绍 创作者活动 UGC→抖音/小红书 年终报告 AI 搜索

我做了什么：转介绍海报五版到个人素材库，奖励改为绑车核销保养券，试驾车绑车人取消邀请资格；创作者平台从 0 到 1，再到申诉、AI 审贴、分层配额；UGC 可同步抖音 / 小红书；年终报告可生成 / 分享 / 抽奖；站内亦可 AI 搜索。

满意度：愿意邀、放心邀；发帖规范清楚、可申诉、不通过有理由；认真分享的人少被羊毛党挤占；有内容可发、有成绩可晒。

场景 · 提车绑车、学功能、开权限
车主课堂 功能解锁 注销换号 鸿蒙对齐

我做了什么：车主课堂改为逐题反馈并下线失效排行榜，功能 code 可多选推送零云；试驾车可用企微批量解锁，单次最多 2000 台；注销按绑车人 / 共同用车人 / 潜客分身份核验；鸿蒙扫一扫与「我的」入口对齐安卓 / iOS。

满意度：学功能即时知道对错，不再答完才揭晓；功能开通更快；换号注销路径清楚，多端入口一致。

场景 · 用车中持续活跃，并进入专属服务群
创作者活动 转介绍活动 车主课堂 口碑发布 专属服务群 一对多服务

我做了什么：售后可持续参与创作者活动、转介绍活动、车主课堂与口碑发布；服务管家 IM 答不上来时自动建群，拉入门店管家 / 总部管家 / 店长，形成一对多专属服务；再叠加运营闭环、移动端、五项自动化与群机器人；充电手册 / 资讯 / 素材做成 RAG；会话带维修记录，客户主体改为 vin。

满意度：问得到人、跟得上进度、答得清充电，同时仍能发帖、邀友、学功能。方案目标：响应 5 分钟→2 秒，覆盖 70% 重复咨询；待办及时率 60%→95%；工单响应 30 分钟→1 分钟。

领导记两句即可：潜客售前先看得到真实口碑与公域内容；车主售后既能玩转介绍 / 创作者 / 课堂 / 口碑，又能自动进专属服务群享受一对多服务。共用底座是年终报告、创作者、UGC 公域同步与 AI 搜索。
