战略愿景

成为驱动零跑全球增长的核心智能引擎，构建超百万级用户与伙伴共赢的数智生态。

业务组合上的落点

对应战略意图「强体验」与「助决策」。其余业务组合不在这两年的主责范围。
强体验

提升公域投放效率

内容供给

公域投放要的不是多开一个站内频道，而是让车主和创作者愿意、并能稳定地在抖音、小红书、汽车之家等公域发帖。两年做的是从 0 到 1 把这条供给链建起来，再让审核和采集自己运转。

创作者平台

2025 从 0 到 1：达人招募、任务、奖励、站外发帖覆盖抖音 / 小红书 / 汽车之家 / 懂车帝 / 头条 / 微博。2026 主投入 13 份：OCR、申诉、AI 自动审核、开放普通用户、分层报名配额、数皆看板与补推。把活动报名工具做成可审核、可分层的公域内容供给中台。

口碑生产

问卷二次打扰改为抓汽车之家口碑：1.0 精简维度，2.0 取消问卷改抓取，3.0 按 9 月 17 日前后统一历史口径。指标从回收量改为点评量、单条处理耗时、详情转化，让公域口碑能直接用于站内决策与投放。

投放工具

UGC 可同步抖音与小红书；分享组件统一；专题页用 uid / openid 溯源；登录浮层按渠道管理，并可按渠道看 PV / UV。公域帖既能发得出去，也能回到站内量出投放效果。

消息订阅

补齐潜客消息订阅能力，活动 / 试驾 / 跟进等关键节点可触达；与注册转化、转介绍接受邀请衔接，减少错过通知与漏跟进，让公域回流后的触达可运营。

助决策

提升车主服务

主责子系统

车主服务的核心是服务管家 IM：用户在 APP 里问得到人，门店和总部跟得上，重复咨询由系统先答。同一条主线从自动建群叠到自动化和群机器人，不另起炉灶。

服务 IM

一期自动建群与三级权限 → 二期运营闭环 → 移动端 → 大区 / 小区权限与根因修复 → 五项自动化（第一次写 ROI：22 人天、投入 4.4 万、年收益测算 36 万、ROI 约 7.1）→ 群机器人可独立回复。

充电问答

手册充电章节、充电资讯、IM 素材做成 RAG。只答充电；高压用电、费用、需到店诊断、改装破解使用固定拒绝话术。置信度不足就不答，方案目标为首响不超过 3 秒。

服务效率

敏感词自动建单、跟进单强制截图、推送按订单 / 充电桩状态触发。试驾车用企微批量解锁功能，单次最多 2000 台，减少门店重复答题，把管家时间留给复杂问题。

数据主体

客户主体从 uid 改为 vin；工单带触发前后各 20 条群消息；会话直接调用用户信息、销服维修记录和素材库，让管家决策有据，而不是靠记忆补位。

02　用户视角 · 我对用户的贡献

潜客 · 售前　｜　车主 · 售后

LEAPMOTOR 两列重点场景：场景 → 我做了什么 → 满意度
底部为全场景贯通能力
潜客 · 售前
认知种草与转化入口
场景 · 看车、看口碑、被内容种草，并完成接受邀请 / 留资转化

我做了什么

  • 查看口碑口碑取消问卷，改抓汽车之家：1.0 精简维度 → 2.0 抓取 → 3.0 统一历史口径，让潜客直接查看真实口碑。
  • 内容种草创作者与 UGC 内容可触达潜客；专题页 uid / openid 溯源，分享组件统一，公域种草能回到站内量效果。
  • 转介绍接受邀请接受邀请页先勾隐私再发验证码；邀请码「6 个月未留资」改为按注册时间起算，减少误伤。
  • 消息订阅通知补齐潜客消息订阅能力，活动 / 试驾 / 跟进节点可触达，减少错过关键通知。

满意度：少被二次问卷打扰，真实口碑与种草内容看得清；接受邀请流程合规清楚；关键节点有通知，少漏跟进。

车主 · 售后
活动参与与专属服务
场景 · 学功能、开权限，并持续参与活动；自动进入专属服务群，享受一对多服务

我做了什么

  • 活动参与售后可持续参与转介绍活动、车主课堂与口碑发布，把用车活跃变成可运营的种草与裂变。
  • 车主课堂课堂改为逐题反馈；功能 code 可多选推送；试驾车企微批量解锁最多 2000 台，减少门店重复答题。
  • 专属服务群服务管家 IM 答不上来时自动建群，拉入门店管家 / 总部管家 / 店长；叠加运营闭环、移动端、五项自动化与群机器人，一对多跟进。

满意度：学功能即时知道对错，功能开通更快；问得到人、跟得上进度，活动与服务不断档。方案目标：响应 5 分钟→2 秒，覆盖 70% 重复咨询；待办及时率 60%→95%；工单响应 30 分钟→1 分钟。

全场景贯通
创作者活动

2025 从 0 到 1：达人招募、任务、奖励与站外发帖。2026 补齐申诉、AI 审贴、分层配额，并开放普通用户。潜客 / 车主都能参与，把公域内容供给做成可审核、可分层的中台能力。

年终报告

支持生成、分享与抽奖；售前售后都能回顾用车 / 互动成绩并二次传播。作为情感触点，把站内活跃沉淀成可晒、可邀的内容资产。

AI 搜索

站内引入 AI 搜索，热度可配；用户更快找到活动、功能与内容。与内容种草、课堂、服务问答衔接，减少「搜不到、问不明」带来的流失。

UGC 公域同步

UGC 可同步抖音 / 小红书；发得出去，也能回到站内看投放效果。让车主与创作者的真实表达持续为潜客种草，打通公域回流链路。

领导记两句：潜客售前看得到真实口碑，接受邀请与消息订阅顺畅；车主售后能参与活动 / 课堂 / 口碑，并能自动进专属服务群。
